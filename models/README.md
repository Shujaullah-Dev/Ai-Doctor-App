# Download a GGUF Model

Place your GGUF model file here and rename it to `model.gguf`, or browse to any `.gguf` file in **Settings**.

## Recommended small models (for testing)

Download a quantized instruct model from Hugging Face, for example:

- [Llama 3.2 3B Instruct Q4_K_M](https://huggingface.co/bartowski/Llama-3.2-3B-Instruct-GGUF)
- [Phi-3 Mini 4K Instruct Q4_K_M](https://huggingface.co/microsoft/Phi-3-mini-4k-instruct-gguf)
- [Qwen2.5 3B Instruct Q4_K_M](https://huggingface.co/Qwen/Qwen2.5-3B-Instruct-GGUF)

Use **Q4_K_M** or **Q5_K_M** quantization for a good balance of quality and speed on desktop CPUs.

## File name

The default path the app looks for is:

```
models/model.gguf
```

You can change this path anytime in **Settings → Browse**.
